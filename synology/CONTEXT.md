# synology

시놀로지 NAS 에 누군가 SSH 로 들어오면 디스코드 채널에 바로 알리는 도구의 용어집이다.

## Language

**SSH 접속**:
다른 기기가 SSH 로 인증을 통과해 NAS 에 연결을 연 일. 셸·SFTP·scp·명령 실행이 모두 해당하고, 연결 하나가 1건이다. 실패한 로그인 시도·로그아웃·연결 끊김은 해당하지 않는다.
_Avoid_: SSH 로그인 (실패 시도나 로그아웃까지 떠올리게 한다), SSH 연결

**출발지**:
**SSH 접속**을 건 기기의 IP 주소.
_Avoid_: 소스, 클라이언트 주소, 접속 IP

**접속 알림**:
**SSH 접속** 하나마다 디스코드 채널에 보내는 메시지 하나. NAS 이름, 사용자, **출발지**, 시각을 담는다.
_Avoid_: 로그인 알림, 경보

**감지 장치**:
NAS 에 놓여 **SSH 접속**을 알아채고 **접속 알림**을 보내게 하는 것. DSM 업데이트가 지울 수 있다.
_Avoid_: 훅, 트리거

**감시 시작 알림**:
NAS 가 켜질 때 **감지 장치**가 제자리에 있는지 확인한 뒤 디스코드 채널에 보내는 메시지 하나. 이 알림이 오지 않으면 감시가 멈춘 것이다.
_Avoid_: 하트비트, 부팅 알림
