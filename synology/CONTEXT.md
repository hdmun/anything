# synology

시놀로지 NAS 에 누군가 SSH 로 들어오면 디스코드 채널에 바로 알리는 도구의 용어집이다.

## Language

**SSH 접속**:
다른 기기가 SSH 로 인증을 통과해 NAS 에 연결을 연 일. 셸·SFTP·scp·명령 실행이 모두 해당하고, 연결 하나가 1건이다. 실패한 로그인 시도·로그아웃·연결 끊김은 해당하지 않는다.
_Avoid_: SSH 로그인 (실패 시도나 로그아웃까지 떠올리게 한다), SSH 연결

**출발지**:
**SSH 접속**을 건 기기의 IP 주소.
_Avoid_: 소스, 클라이언트 주소, 접속 IP

**접속 알림**:
**SSH 접속** 하나마다 디스코드 채널에 보내는 메시지 하나. NAS 이름, 사용자, **출발지**, 시각을 담는다. 시각은 늦게 보내더라도 **SSH 접속**이 일어난 시각이다.
_Avoid_: 로그인 알림, 경보

**감지 장치**:
NAS 에서 계속 돌며 **SSH 접속**을 알아채고 **접속 알림**을 보내는 것. SSH 접속 경로 밖에 있어서, 멈추거나 느려도 SSH 접속에는 영향이 없다. 멈춘 동안 들어온 SSH 접속은 다시 돌기 시작할 때 늦게 알린다. 처음 설치하기 전에 들어온 SSH 접속은 알리지 않는다.
_Avoid_: 훅, 트리거, 감시 프로세스

**감시 시작 알림**:
**감지 장치**가 돌기 시작할 때마다 디스코드 채널에 보내는 메시지 하나. 시작한 이유를 담는다: `부팅`(NAS 를 켬), `다시 시작`(멈췄다가 다시 돎), `설치`(사람이 감지 장치를 새로 올림). `다시 시작` 은 무언가 고장 났다는 신호다. NAS 를 켠 뒤 이 알림이 오지 않으면 감시가 멈춘 것이다.
_Avoid_: 하트비트, 부팅 알림
