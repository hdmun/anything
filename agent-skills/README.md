# agent-skills

직접 만든 에이전트 스킬의 원본이다. `install.ps1` 이 원본을 에이전트의 skills 폴더로 **복사**한다. 복사된 폴더는 직접 고치지 않는다.

| 묶음 | 대상 skills 폴더 | 스킬 |
|---|---|---|
| `shared/` | `~/.claude/skills`, `~/.agents/skills` | `orca-handoff` |
| `claude/` | `~/.claude/skills` | `rename-session` (Claude 판: `scripts/rename.py` 로 이름을 바로 적용) |
| `agents/` | `~/.agents/skills` (Codex·agy) | `rename-session` (Codex·agy 판: 제목 후보만 추천) |

- 묶음 폴더 바로 아래의 폴더 하나가 스킬 하나다. 이 폴더와 묶음 폴더에 바로 놓인 파일(이 README 등), 묶음이 아닌 폴더는 무시한다.
- 대상은 이 2개로 고정이다. `CLAUDE_CONFIG_DIR` 은 보지 않는다. 서브 계정 폴더의 `skills` 는 agent-accounts 가 `~/.claude/skills` 로 거는 junction 이라서 따로 맞추지 않는다.
- 대상의 부모 폴더(`~/.claude`, `~/.agents`)가 없으면 그 도구가 설치되지 않은 PC 로 보고 건너뛴다.
- 원본에 없는 스킬 폴더는 보지도 지우지도 않는다. 원본에서 스킬을 빼도 PC 에 남은 폴더는 사람이 지운다.

## 스킬을 고치는 법

1. 이 폴더의 원본을 고치거나 더한다
2. 원본을 커밋한다
3. 저장소 루트에서 `pwsh -NoProfile -File agent-skills/install.ps1` 을 실행한다 (먼저 보려면 `-Check`)

`install.ps1` 은 pc-setup 의 **저장소 도구**다([../pc-setup/repo-tools.md](../pc-setup/repo-tools.md)). 셋업이 `-Check` 와 맞춤 실행을 대신 부른다.

## 생성 표시와 덮어쓰기

복사한 스킬 폴더에는 생성 표시 파일 `.agent-skills` 를 둔다. 내용 비교에서는 이 파일을 뺀다. 파일 내용은 CRLF·CR 을 LF 로 바꾼 뒤 비교한다.

| 대상 상태 | `-Check` | 맞춤 |
|---|---|---|
| 없음 | `다름` | 복사 |
| 심볼릭 링크·junction | `다름` | 링크만 지우고 복사 (가리키던 폴더는 그대로) |
| 표시 있음, 내용 같음 | `그대로` | `그대로` |
| 표시 있음, 내용 다름 | `다름` | 비우고 복사 |
| 표시 없음, 내용 같음 | `다름` | 표시만 쓴다 |
| 표시 없음, 내용 다름 | `할 일` | `할 일`. `-Force` 면 `<skills 폴더>.prev/<스킬>` 로 옮긴 뒤 복사 |
| 폴더가 아니라 파일 | `실패` | `실패` |

`-Force` 백업 자리에 이전 백업이 있으면 지우고 새로 둔다.

## 출력

표준 출력은 한 줄이다. 셋업이 이 줄을 읽는다.

| 출력 | 뜻 |
|---|---|
| `그대로` | 모든 대상이 원본과 같다 (대상이 하나도 없을 때도) |
| `다름 (~/.claude/skills/<스킬>, …)` | `-Check`: 맞출 대상이 있다 |
| `바꿈 (~/.claude/skills/<스킬>, …)` | 그 대상을 맞췄다 |
| `할 일: …` | 생성 표시가 없고 내용이 다른 폴더가 있다 (위 절) |
| `실패: …` | 원본 폴더가 없음, 같은 이름 스킬이 두 묶음에 있음, 스킬 자리에 파일이 있음, 읽기·쓰기 오류 |

여러 대상의 결과가 섞이면 `실패` > `할 일` > `다름`/`바꿈` > `그대로` 순서로 하나만 보인다. `할 일`·`실패` 가 있어도 다른 대상은 맞춘다. 처리 순서는 `shared` → `claude` → `agents`, 묶음 안에서는 스킬 이름 순서, 대상은 `.claude` → `.agents` 다. `-Verbose` 이면 대상마다 결과 한 줄을 더 보여 준다.

## 왜 이렇게 했나

- **복사**로 건다. 링크로 걸면 저장소 폴더를 옮기거나 워크트리를 지울 때 스킬이 깨진다. 대신 원본을 고친 뒤에는 `install.ps1` 을 다시 실행해야 반영된다.
- `-Force` 백업을 skills 폴더 **밖**(`skills.prev/`)에 둔다. skills 폴더 안에 두면 에이전트가 백업 폴더를 스킬로 읽는다.
- 링크는 링크 항목만 지운다(재귀 삭제를 쓰지 않는다). junction 을 재귀로 지우면 가리키던 폴더의 내용까지 지워질 수 있다.
- 줄바꿈을 무시하고 비교한다. git 의 줄바꿈 변환(`core.autocrlf`)이 PC 마다 달라서, 같은 원본도 체크아웃된 바이트가 다를 수 있다.
- `rename-session` 은 이름이 같은 두 판을 묶음으로 나눠 둔다. Claude 판의 `rename.py` 는 Claude Code 세션 파일을 고치므로 Codex·agy 에서는 쓸 수 없다.
