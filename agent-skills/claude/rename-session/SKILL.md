# rename-session

대화 맥락을 요약해 세션 이름을 정하고, 세션 transcript에 `custom-title` 항목을 추가해 적용한다. `/rename`은 내장 명령이라 스킬에서 호출할 수 없어서, `/resume` 목록이 읽는 것과 같은 항목을 스크립트로 직접 쓴다.

## 절차

1. **맥락 파악**: 지금까지 대화에서 실제로 한 일(주제, 대상 프로젝트/파일, 결과)을 본다. 첫 질문보다 *최종적으로 한 일*을 우선한다. 세션이 짧거나 모호하면 사용자에게 한 줄로 물어본다.
2. **이름 짓기**: 아래 규칙으로 후보 1개를 만든다.
   - 형식: `(YYYY.MM.DD) 핵심 주제` — 날짜는 오늘 날짜(시스템이 알려준 Today's date). 사용자가 날짜 없이 원하면 생략.
   - 사용자 언어(한국어면 한국어)로, 15~35자. 나중에 `/resume`에서 훑어볼 때 무슨 세션인지 바로 알아야 하므로 "작업 확인", "질문" 같은 빈 표현은 피하고 구체 명사를 쓴다.
   - 예: `(2026.10.17) rename-session 스킬 작성`, `(2026.09.07) relay 파이프라인 구축과 첫 실전`
   - 사용자가 이름을 직접 줬으면 그대로 쓴다.
3. **적용**: 실행한다.
   ```
   python ~/.claude/skills/rename-session/scripts/rename.py "<이름>"
   ```
   스크립트는 현재 작업 디렉터리의 프로젝트 폴더(`$CLAUDE_CONFIG_DIR/projects/…`)에서 가장 최근 수정된 세션 파일에 기록한다. 세션 ID를 알면 `--session <id>`를 붙인다(병렬 세션이 있을 때 오기록 방지).
4. **보고**: 적용한 이름 한 줄 + 대상 세션 ID 앞 8자리만 알려준다. 재시작/`/resume` 목록에서 반영된다고 덧붙인다.

## 주의
- 이름 변경은 되돌리기 쉬우므로(다시 실행) 확인 질문 없이 바로 적용한다.
- 같은 폴더에서 다른 세션이 동시에 돌고 있으면 "가장 최근 파일"이 다른 세션일 수 있다. 그 경우 `--session`으로 지정한다.
