# 작업: Antigravity CLI 상태 줄을 Claude Code 상태 줄과 같게 만든다

## 배경
- 저장소: `C:\workspace\anything` (Windows 11, PowerShell 7)
- Claude Code용 상태 줄은 `claude-statusline/statusline.ps1` 에 있다.
  - 표시 항목과 동작은 `claude-statusline/README.md` 에 있다.
  - 작업 전에 이 두 파일을 먼저 읽는다.
- 이번 작업은 같은 상태 줄을 Antigravity CLI(agy)에도 만드는 것이다.

## 목표 출력 (Claude Code 버전과 같게)
```
🤖 <모델> (<effort>) | 📁 <디렉터리> | 🌿 <브랜치>*
🧠 ██████░░░░ 62% | 124k/200k | ⏳ 5h 70% left (🔄 2h9m) | 💰 $1.23 | ⏱ 1h23m
📝 recap: <최근 요약, 터미널 폭에 맞춰 자름>
```
- 1줄 (작업 환경): 모델(effort), 디렉터리, git 브랜치. 변경 사항이 있으면 `*` 를 붙인다.
- 2줄 (사용량): 컨텍스트 게이지와 %, 토큰 사용량/총량, 남은 사용 한도와 리셋까지 남은 시간, 세션 과금액, 세션 실행 시간
- 3줄: 최근 recap이나 요약. 없으면 줄 자체를 출력하지 않는다.
- 색은 ANSI 코드로 넣는다.
  - 모델은 청록, 디렉터리는 파랑, 브랜치는 보라
  - 사용량은 50% 미만 초록, 80% 미만 노랑, 80% 이상 빨강
  - 부가 정보는 흐리게 표시한다.
- 값이 없는 항목은 오류 없이 뺀다.

## 진행 순서
1. **agy가 상태 줄을 지원하는지부터 확인한다.** 공식 문서와 agy 설정 파일, `--help` 로 확인한다. 추측하지 않는다.
   - 커스텀 상태 줄(또는 footer/prompt) 명령을 설정할 수 있는가? 설정 키와 파일 위치는 어디인가?
   - 스크립트에 어떤 데이터를 넘겨주는가? stdin JSON인가, 환경 변수인가? 필드 이름은 무엇인가?
   - 여러 줄 출력과 ANSI 색을 지원하는가? 화면은 언제 다시 그려지는가?
   - 실제 입력을 임시 파일로 한 번 저장해서 필드를 눈으로 확인한다. 확인이 끝나면 저장 코드와 임시 파일을 지운다.
2. **지원하지 않으면 여기서 멈추고 보고한다.** 확인한 근거(문서 링크, 명령 출력)를 붙이고, 가능한 대안을 하나 제안한다.
3. **항목별 대응표를 만들어 보고한다.** Claude Code 버전의 항목마다 agy에서 얻을 수 있는 필드를 적는다. 얻을 수 없는 항목은 "없음"으로 적고 뺀다. 값을 지어내지 않는다.
4. **구현한다.**
   - 파일: `agy-statusline/statusline.ps1` 과 `agy-statusline/README.md`
   - 공통 로직(색, 게이지, 시간 형식, 한글 폭을 고려한 자르기)은 Claude Code 버전과 똑같이 한다. 공유 모듈로 빼는 것이 낫다면 그렇게 하자고 제안만 하고, 기존 파일은 고치지 않는다.
   - agy 설정 파일에는 상태 줄 항목만 더하고, 다른 설정은 그대로 둔다.
5. **시험한다.**
   - 예시 입력을 스크립트에 넣어 실행하고, 색 코드를 지운 결과를 보고한다.
   - 값이 빈 입력, 잘못된 입력, 좁은 폭(`COLUMNS=80`)에서도 돌려 본다.

## 주의
- PowerShell 변수는 대소문자를 구분하지 않는다. 색 코드용 `$E` 와 겹치는 `$e` 같은 이름을 쓰지 않는다. 실제로 이 문제로 출력이 깨진 적이 있다.
- 대화 기록 같은 큰 파일은 끝부분만 읽는다 (예: 마지막 2MB).
- 한글과 이모지는 한 글자가 2칸이다. 자를 때 이 폭을 기준으로 계산한다.

## Git 규칙 (저장소 CLAUDE.md / AGENTS.md 를 따른다)
- 브랜치는 `hdmun/agy-statusline` 이다. `main` 에서 바로 작업하지 않는다.
- 커밋 메시지는 Conventional Commits 형식으로 쓴다.
  - 예: `feat(agy-statusline): ...`
  - 설명은 한국어로, `~한다` 체로 쓴다.
- 이 PC에는 Git 작성자 정보가 설정되어 있지 않다. 커밋할 때만 아래 옵션을 붙이고, Git 설정 자체는 바꾸지 않는다.
  `git -c user.name=hdmun -c user.email=48820928+hdmun@users.noreply.github.com commit ...`
- 푸시하지 않는다.
