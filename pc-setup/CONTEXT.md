# pc-setup

Windows 11 집 PC 를 원하는 상태(앱·설정 파일·Windows 설정·저장소 도구)로 맞추는 도구의 용어집이다.

## Language

**선언**:
PC 가 있어야 할 상태를 적은 파일들. 앱 목록, 설정 파일 목록, **Windows 설정** 목록, **저장소 도구** 목록으로 이루어진다. 저장소에 있는 **선언**이 정본이고, PC 는 거기에 맞춘다.
_Avoid_: 매니페스트, 설정(설정 파일과 헷갈린다)

**셋업**:
에이전트 CLI 가 `SETUP.md` 를 읽고 **선언**대로 PC 를 맞추는 실행. 사람이 `pc-setup` 폴더에서 에이전트를 띄우고 시작 줄 하나로 시작한다. 여러 번 돌려도 결과가 같다(멱등). 새 PC 에서도, 이미 셋업한 PC 에서도 시작 줄이 같다. **선언**에 없는 것(앱·설정 파일·Windows 설정)은 보지도, 알리지도, 지우지도 않는다.
_Avoid_: 설치(앱 하나 설치와 헷갈린다), 동기화

**부트스트랩**:
아무것도 없는 Windows 에서 저장소를 받고, **셋업**을 진행할 에이전트 CLI 하나를 준비하기까지의 과정. **셋업**은 사람이 그 에이전트를 띄워서 시작한다.
_Avoid_: 초기 설치, 첫 셋업

**원천**:
**선언**의 앱 하나를 받아 오는 곳. winget(msstore 소스 포함), scoop, nvm(Node 만), pnpm(npm 레지스트리 패키지를 전역으로), go(Go 도구를 `go install` 로), 공식 배포(앱 제작사가 직접 내는 설치 경로)가 있다. 앱마다 원천이 하나다.
_Avoid_: 소스(winget `--source` 와 헷갈린다), 저장소(이 git 저장소와 헷갈린다)

**런타임**:
코드를 빌드하거나 실행하는 언어 실행 환경. 앱의 한 종류다(Go·Node·Bun·Python·Ruby·Flutter).
_Avoid_: SDK, 언어

**버전 줄**:
앱 버전 가운데 **선언**이 고정하는 앞부분(Python 3.13, Ruby 3.4, Ubuntu 24.04, Node 26). 그 안의 패치 버전은 고정하지 않는다.
_Avoid_: 메이저 버전(줄이 마이너 버전까지인 경우가 있다), 채널

**저장소 도구**:
이 저장소 안에 있는 도구 가운데 PC 에 설치해야 쓸 수 있는 것. **셋업**이 **선언**의 목록대로 설치한다. 확인과 설치는 도구가 저장소에 함께 둔 설치 스크립트(`install.ps1`)가 하고, **셋업**은 그 도구의 `install.ps1` 만 실행한다.
_Avoid_: 스크립트, 유틸

**승격 단계**:
**셋업** 맨 처음에, 맞춰야 할 승격 항목과 일반 권한으로는 확인할 수 없는 승격 **저장소 도구**를 임시 스크립트 하나로 모아 관리자 권한(RunAs)으로 한 번 실행하는 부분. 실행 1회에 UAC 를 최대 한 번 묻고, 둘 다 없으면 묻지 않는다. **부트스트랩**에는 없다.
_Avoid_: 승격 묶음, 관리자 단계

**계획**:
**셋업**에서 확인이 끝난 뒤 맞출 항목·**원천**·참고한 공식 문서·**승격 단계** 스크립트 내용을 사람에게 보여 주는 목록. 사람이 승인해야 맞춤이 시작된다.

**설정 파일**:
앱이 읽는 사용자 설정 가운데 **선언**이 다루는 것. 정본은 저장소에 있다. PC 의 원래 자리에서는 링크로 걸거나, 그 자리의 **로컬 파일**이 불러온다.
_Avoid_: dotfile, 구성 파일

**로컬 파일**:
**설정 파일**의 원래 자리에 놓인 PC 전용 일반 파일. 저장소 **설정 파일**을 불러오는 줄과 그 PC 에만 맞는 값을 담는다. 저장소에 들어가지 않는다.
_Avoid_: 스텁, 껍데기

**Windows 설정**:
앱이 아니라 Windows 자체가 가진 설정 가운데 **선언**이 다루는 것(탐색기 옵션·전원·원격 데스크톱 등). 앱이 읽는 설정은 **설정 파일**이다.
_Avoid_: 시스템 설정, OS 설정, 레지스트리 설정(레지스트리가 아닌 것도 있다)

**에이전트 폴더**:
Claude Code·Codex·agy 같은 에이전트 CLI 가 설정·로그인·기록을 두는 폴더. agent-accounts 의 계정 폴더도 여기에 든다. **셋업**은 건드리지 않는다.
_Avoid_: 설정 디렉터리(**설정 파일**과 헷갈린다), 계정 폴더(agent-accounts 가 만드는 한 종류일 뿐이다)
