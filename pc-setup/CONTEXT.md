# pc-setup

Windows 11 집 PC 를 원하는 상태(앱·설정 파일·저장소 도구)로 맞추는 도구의 용어집이다.

## Language

**선언**:
PC 가 있어야 할 상태를 적은 파일들. 앱 목록, 설정 파일 목록, **저장소 도구** 목록으로 이루어진다. 저장소에 있는 **선언**이 정본이고, PC 는 거기에 맞춘다.
_Avoid_: 매니페스트, 설정(설정 파일과 헷갈린다)

**셋업**:
PC 를 **선언**된 상태로 맞추는 실행. 여러 번 돌려도 결과가 같다(멱등). 새 PC 에서도, 이미 셋업한 PC 에서도 같은 명령이다.
_Avoid_: 설치(앱 하나 설치와 헷갈린다), 동기화

**부트스트랩**:
아무것도 없는 Windows 에서 저장소를 받아 **셋업**을 처음 실행하기까지의 과정. **셋업**에 들어가기 전 단계만 가리킨다.
_Avoid_: 초기 설치, 첫 셋업

**원천**:
**선언**의 앱 하나를 받아 오는 곳. winget(msstore 소스 포함), scoop, 공식 배포(앱 제작사가 직접 내는 설치 경로)가 있다. 앱마다 원천이 하나다.
_Avoid_: 소스(winget `--source` 와 헷갈린다), 저장소(이 git 저장소와 헷갈린다)

**저장소 도구**:
이 저장소 안에 있는 도구 가운데 PC 에 설치해야 쓸 수 있는 것. **셋업**이 **선언**의 목록대로 설치한다.
_Avoid_: 스크립트, 유틸

**승격 단계**:
**부트스트랩**이나 **셋업** 안에서 관리자 권한이 필요한 항목을 모아 한 번에 처리하는 부분. 실행 1회에 UAC 를 한 번만 묻는다.
_Avoid_: 승격 묶음, 관리자 단계

**설정 파일**:
앱이 읽는 사용자 설정 가운데 **선언**이 다루는 것. 정본은 저장소에 있다. PC 의 원래 자리에서는 링크로 걸거나, 그 자리의 **로컬 파일**이 불러온다.
_Avoid_: dotfile, 구성 파일

**로컬 파일**:
**설정 파일**의 원래 자리에 놓인 PC 전용 일반 파일. 저장소 **설정 파일**을 불러오는 줄과 그 PC 에만 맞는 값을 담는다. 저장소에 들어가지 않는다.
_Avoid_: 스텁, 껍데기

**예상 결과**:
깨끗한 Windows 시험 환경(Windows Sandbox)에서 **셋업**을 돌릴 때 실제 PC 와 같은 결과가 나올 수 없는 항목과, 그 항목에 허용하는 결과(건너뜀·실패·할 일)를 적은 목록. 시험 환경이 실제 PC 와 달라서 생기는 차이만 적는다. 목록에 없는 항목은 실제 PC 와 같은 결과를 내야 한다.
_Avoid_: 예외 목록, 허용 목록
