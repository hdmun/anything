# Windows 설정 (windows-settings.md)

**셋업**이 맞추는 **Windows 설정**의 **선언**이다. 진행 방법은 [SETUP.md](SETUP.md) 를 따른다. 원하는 상태만 말로 적는다. 레지스트리 경로·값과 명령은 셋업할 때 공식 문서(Microsoft Learn 등)에서 찾는다.

## 기본 규칙

- **확인**: 지금 상태를 일반 권한으로 읽어, 원하는 상태 칸과 같으면 `그대로`다.
- **범위**: 원하는 상태에 "현재 사용자"라고 적은 설정은 현재 사용자 설정만 바꾼다. 나머지는 이 PC 전체 설정이다.
- **승격**: 승격 칸이 `필요`인 설정은 승격 항목이다(**승격 단계**에서 맞춘다).

## 원격 데스크톱

- 확인: 아래 세 가지를 모두 통과해야 `그대로`다.
  1. 이 PC 로의 원격 데스크톱 연결이 허용돼 있다.
  2. 연결할 때 네트워크 수준 인증을 요구한다.
  3. Windows 방화벽의 "원격 데스크톱" 규칙 그룹이 있고, 그 그룹의 규칙이 모두 켜져 있다.
- 규칙 그룹 자체가 없으면 맞추지 않고 `실패: 원격 데스크톱 방화벽 규칙이 없다`로 기록한다.
- 원격 데스크톱 알림은 별도의 **저장소 도구**(`rdp-notify`, [repo-tools.md](repo-tools.md))가 맡는다.

## 최대 절전

- 확인: 최대 절전이 꺼져 있다(최대 절전 설정 값이 없어도 꺼진 것으로 본다).

## 전원

- 확인: 지금 쓰는 전원 구성표에서, AC 전원일 때 "절전 모드로 전환"이 "안 함"이고 "화면 끄기"가 15분이다.
- 배터리(DC) 설정은 보지도 바꾸지도 않는다.
