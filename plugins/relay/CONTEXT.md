# relay

설계자·진행자·구현자·리뷰어 네 역할로 한 태스크를 spec부터 머지 직전까지 옮기는 파이프라인의 용어집이다.

## Language

### 에이전트 CLI

**모델 계열**:
역할에 배정하는 모델의 지정 단위(예: Opus, Sonnet, codex 기본 모델). 특정 버전이 아니며, 실제로 쓰인 버전은 사후 기록으로만 남는다.
_Avoid_: 모델 버전, 모델 ID

**검증된 버전**:
실제 기동과 전달 확인을 통과했다고 사람이 등록한 에이전트 CLI 버전. 목록 밖의 버전은 작동하더라도 미검증으로 본다.
_Avoid_: 지원 버전, 호환 버전

### 시도와 라운드

**기동 실패**:
워커가 태스크 프롬프트를 받기 전에 실패한 것. Orca가 실패로 보고한 경우와 **전달 확인**에 실패한 경우를 모두 포함한다. 환경 문제이므로 라운드로 세지 않는다.
_Avoid_: 라운드, 재시도 라운드

**전달 확인**:
기동 직후, 워커가 태스크 프롬프트를 실제로 받았다는 양성 증거를 확인하는 일. Orca의 "입력 수락"은 전달의 증거가 아니다.
_Avoid_: 기동 확인, 준비 확인

**구현 라운드**:
게이트를 통과해 커밋으로 남은 구현 한 번.
_Avoid_: 구현 시도, 회차

**리뷰 라운드**:
리뷰어가 낸 리뷰 리포트 하나.
_Avoid_: 리뷰 회차, 리뷰 시도

**총 라운드**:
한 태스크의 구현 라운드와 리뷰 라운드를 합한 수. 기동 실패는 포함하지 않는다.
_Avoid_: 전체 시도 수
