# rdp-notify

이 PC에 원격 데스크톱으로 누군가 들어오면 디스코드 채널에 바로 알리는 도구의 용어집이다.

## Language

**RDP 접속**:
다른 기기에서 원격 데스크톱으로 이 PC의 세션에 들어온 일. **새 로그온**과 **재접속**만 해당하고, 실패한 로그인 시도·로그오프·연결 끊김·**콘솔 접속**은 해당하지 않는다.
_Avoid_: RDP 로그인 (실패 시도나 로그오프까지 떠올리게 한다)

**새 로그온**:
세션이 없던 상태에서 원격으로 새 세션을 연 **RDP 접속**.
_Avoid_: 로그인

**재접속**:
연결이 끊긴 채 남아 있던 세션에 원격으로 다시 붙은 **RDP 접속**.
_Avoid_: 재연결, 세션 복귀

**콘솔 접속**:
PC 앞에서 직접 세션에 들어오거나 다시 붙은 일. **RDP 접속**이 아니므로 알리지 않는다.
_Avoid_: 로컬 로그인

**출발지**:
**RDP 접속**을 건 기기의 IP 주소.
_Avoid_: 소스, 클라이언트 주소

**접속 알림**:
**RDP 접속** 하나마다 디스코드 채널에 보내는 메시지 하나. PC 이름, 사용자, **출발지**, 시각, 종류(**새 로그온** 또는 **재접속**)를 담는다.
_Avoid_: 로그인 알림, 경보
