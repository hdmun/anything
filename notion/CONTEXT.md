# Notion 중복 스크랩 정리 도메인 모델 (CONTEXT)

이 문서는 노션 스크랩 문서 중복 정리 도구의 비즈니스 용어와 도메인 규칙을 정의합니다.

## 용어 사전 (Glossary)

*   **스크랩 정리 (Scrap Clean-up)**
    *   스크랩된 문서들이 저장되는 부모 카테고리 루트 페이지입니다. (ID: `af301053-2e1a-4d8c-a071-87c096c8cb33`)
*   **카테고리 (Category)**
    *   '스크랩 정리' 페이지 하위에 위치한 개별 테마 폴더 페이지들입니다. (예: IT/개발, 건강/운동 등)
*   **중복 스크랩 페이지 (Duplicate Scrap Page)**
    *   전체 카테고리를 통틀어 **제목(Title)이 완전히 동일한** 스크랩 페이지들입니다.
*   **보존 대상 페이지 (Retained Page)**
    *   중복 스크랩 페이지 그룹 중에서 **가장 최근에 생성된(Created Time이 가장 늦은)** 페이지입니다. 이 페이지는 원래 카테고리 위치에 그대로 보존됩니다.
*   **중복 정리 폴더 (Duplicate Archive Folder)**
    *   보존 대상이 아닌 중복 페이지들이 이동할 임시 보관용 카테고리 페이지입니다. 페이지 이름은 `"중복 정리"`로 정의합니다.

## 동작 규칙 (Operations)

1.  **동적 폴더 조회 및 생성**: '스크랩 정리' 하위에 `"중복 정리"` 이름의 카테고리 페이지가 있는지 조회합니다. 없다면 새로 생성하여 이동 대상으로 삼습니다.
2.  **전체 페이지 수집**: '스크랩 정리' 하위 모든 카테고리 폴더 내의 자식 페이지를 재귀적으로 스캔하여 제목, 생성 시간, 현재 카테고리 정보를 수집합니다.
3.  **중복 판정 및 분류**:
    *   수집한 페이지를 제목 기준으로 그룹화합니다.
    *   각 그룹 내에서 가장 최근에 생성된 페이지 하나를 **보존 대상**으로 선정합니다.
    *   그 외의 페이지들은 **정리 대상**으로 분류합니다.
4.  **페이지 이동**: 정리 대상 페이지들을 `"중복 정리"` 폴더로 이동시킵니다. (이때, 이미 "중복 정리" 폴더 내에 있는 페이지는 제외합니다.)
